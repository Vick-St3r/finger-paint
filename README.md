# Finger Paint

Finger Paint is an interactive paint application with your actual finger and camera! Finger Paint utilizes OpenCv for computer vision and MediaPipe for hand tracking.

## How to run 

1. Go to the latest GitHub release and download zipped file 
2. Unzip paint 
3. Run paint.exe
4. Press q to quit when done (or let it run forever)
